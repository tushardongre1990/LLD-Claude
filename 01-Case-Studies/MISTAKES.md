# Mistakes Log

One line per thing you missed or got wrong, added after each case study's
review. Re-read this before every mock and every real interview: it's the
shortest possible list of *your* weak spots.

Keep each line specific enough to act on. "Missed an invariant" is too
vague; "Missed that a spot can hold only one vehicle, so double-parking was
possible" is useful.
